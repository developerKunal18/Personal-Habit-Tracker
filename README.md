# Personal Habit Tracker

## About

A command-line Python application to create habits,
record daily progress, track streaks, and generate reports.

## Features

- Add and delete habits
- Daily and weekly habit categories
- Mark habits as completed
- View daily progress
- Track pending habits
- Calculate current and longest streaks
- Generate weekly reports
- Generate monthly reports
- Store information in JSON files

## Technologies Used

- Python
- JSON
- File Handling
- Date and Time
- Functions
- Modules

## Installation

No external packages are required.

## How to Run

python main.py

## Data Storage

All habit information and progress records
are stored in JSON files inside the data folder.
